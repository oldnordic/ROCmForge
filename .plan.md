# Plan: Fix Kernel Routing for Non-SwiGLU Architectures & Model Consolidation

## Problem
- **Phi-3** fails with `tensor not found: blk.0.ffn_gate.weight` because it uses standard FFN (no SwiGLU gate), but `CpuLayerWeights` hard-requires `ffn_gate`.
- **LFM2.5** fails with `tensor not found: output_norm.weight` because it uses `token_embd_norm.weight` instead.
- **qwen3.5** GPU decode hits NaN at layer 2 in SSM forward — prefill works, first decode step corrupts. This is a deeper SSM kernel bug.

## Scope

### 1. Add `FfnLayout` trait to `ModelTraits` (2 files)
- **src/config/traits.rs**: Add `FfnLayout` enum (`SwiGLU` vs `Standard`). Set `phi3` → `Standard`, all others → `SwiGLU`.
- **src/config/model_config.rs**: Expose `ffn_layout` on `ModelConfig`.

### 2. Make `ffn_gate` optional in weight loading (~5 files)
- **src/cpu/weights/layer.rs**: Change `ffn_gate: Vec<u8>` → `Option<Vec<u8>>`. Load gate only if tensor exists OR trait says SwiGLU.
- **src/cpu/weights/layer.rs (RFM)**: Same for `load_rfm`.
- **src/cpu/forward.rs**: Branch on `ffn_gate` presence: SwiGLU path (gate GEMV + silu_fuse) vs Standard path (up GEMV + GELU/ReLU — for Phi-3 it's just up→down, no extra activation since Gemma/Phi style).
- **src/cpu/prefill.rs**: Same branching.
- **src/gpu/weights/layer.rs**: Same optional gate for GPU weights.

### 3. Fix `output_norm` fallback (3 files)
- **src/config/tensor_names.rs**: Add `resolve_with_fallback` or make `OutputNorm` try `output_norm.weight` then `token_embd_norm.weight`.
- **src/cpu/weights/model.rs**: Use fallback when loading `output_norm`.
- **src/gpu/weights/model.rs**: Same for GPU.

### 4. Investigate qwen3.5 SSM NaN (1 file, research)
- **src/gpu/forward/layer/ssm.rs**: The NaN appears after `dispatch_gated_delta_net` or `dispatch_gated_norm` at layer 2. Need to add per-kernel NaN checks to isolate which kernel emits NaN.
- Likely candidates: `dispatch_fused_sigmoid_alpha_gate`, `dispatch_conv1d_silu`, `dispatch_gated_delta_net`, or `dispatch_gated_norm`.

### 5. Model consolidation (already done)
- Symlinks created in `/home/feanor/Projects/models/` for all scattered GGUFs.
